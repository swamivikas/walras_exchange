Developer Quickstart

Integrate in 3 Lines of Code

Drop-in compatible with the OpenAI Python and TypeScript SDKs. Simply swap your base URL and API key.

https://api.walras.exchange/v1 
# pip install openai
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",  # Walras Gateway
    api_key="walras_live_org_..."
)

response = client.chat.completions.create(
    model="deepseek-r1",
    messages=[{"role": "user", "content": "Explain quantum cryptography in 1 sentence."}]
)

print(response.choices[0].message.content)
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer walras_live_org_..." \
  -d '{
    "model": "deepseek-r1",
    "messages": [{"role": "user", "content": "Explain quantum cryptography."}]
  }'
